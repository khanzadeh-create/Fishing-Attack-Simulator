 Project Purpose

This project is a phishing attack simulator created strictly for educational purposes. Its goals are to:

-   Raise Awareness: Help users understand how phishing pages work and what they look like without any real-world risk.
-   Teach Detection: Provide a step-by-step report after simulation that teaches key indicators of a real phishing attack (like checking URLs, HTTPS, and design details).
-   Serve as a Training Tool: Can be used by security professionals to train employees, students, and others in cybersecurity hygiene.

 Important Disclaimer

It is emphasized that this project is for legal and educational purposes only.

-    Do not use this project for real phishing attacks.Such actions are illegal and unethical.
-    This project does NOT store, collect, or transmit any data. All information entered on the simulated pages is used solely for immediate display in the report and is then discarded.
-    You are responsible for any use of this code.The developer assumes no liability for the misuse of this project.
-    This project should not be hosted on public servers.It is intended for local, private, and controlled environments for learning.

 Key Features

-   Realistic Simulations: Faithfully recreated login pages of popular services (e.g., Google, Facebook).
-   Step-by-Step Educational Report: After submitting fake credentials, users receive a detailed breakdown of the "attack," explaining how to spot the red flags.
-   No Data Storage: Absolutely zero data persistence. What you type in stays on your computer and goes nowhere else.
-   Clear Warnings: Every simulated page contains visible warnings stating its educational nature.

 Prerequisites

To run this project locally, you need:
   A modern web browser (Chrome, Firefox, Edge).
   A local server (recommended) or you can open the HTML files directly (some features might be limited due to browser security policies).
